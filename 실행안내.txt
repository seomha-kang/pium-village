피움이의 마음마을
동신대학교 학생상담센터 모바일 RPG

1. 바로 실행하기
「피움이의-마음마을.html」 파일을 내려받아 Chrome, Edge 또는 Safari 등 최신 브라우저로 여세요.
그림과 프로그램을 모두 포함한 단일 파일이므로 별도의 설치나 인터넷 연결 없이 실행할 수 있습니다.
휴대폰의 파일 미리보기 앱에서는 게임 실행이 제한될 수 있습니다. 학생 배포에는 웹 호스팅 주소를 사용하는 것이 적합합니다.

2. 조작
휴대폰: 왼쪽 아래 조이스틱을 누른 채 원하는 방향으로 움직이세요.
컴퓨터: 방향키 또는 WASD로 이동하세요.
건물 문 앞의 작은 원 가까이 가면 [입장] 버튼이 켜집니다. 컴퓨터에서는 Enter로도 입장할 수 있습니다.
다섯 건물은 어떤 순서로 방문해도 됩니다.
꽃잎 다섯 개를 모두 모으면 퀘스트 완료 화면에서 마을로 돌아갈 때 엔딩이 나옵니다.

3. 저장
완료한 퀘스트만 이 브라우저의 LocalStorage에 저장합니다. 꽃잎 개수는 완료한 퀘스트 개수로 계산합니다.
기기·브라우저·웹 주소가 달라지거나 브라우저 데이터를 삭제하면 진행 상황이 이어지지 않습니다.
저장 공간이 막힌 환경에서도 플레이할 수 있으나 진행 상황은 보존되지 않을 수 있습니다.

4. 웹 배포 / QR코드
현재 온라인 배포는 실행 승인 정책에 막혀 완료되지 않았습니다. 공개 게임 주소와 QR코드는 아직 없습니다.
「마음마을-소스.zip」을 압축 해제하면 index.html, style.css, content.js, game.js와 assets 폴더가 나옵니다.
이 파일들을 그대로 정적 웹 호스팅에 올리고, 발급된 HTTPS 주소를 QR코드로 만들면 학생들에게 배포할 수 있습니다.
서버 프로그램, 데이터베이스, 로그인, 빌드 도구는 필요하지 않습니다.

5. 포함 기능
하나의 마을, 건물 5개, 조이스틱·키보드 이동, 건물·분수·꽃밭 충돌, 문 접근 감지, NPC 대화,
개인상담 단계 안내, 집단상담 신청 안내, 심리검사 설명과 퀴즈 3개, 고민 O/X 퀴즈 3개,
센터 위치 퀴즈, 중복 없는 꽃잎 수집, 완료 표시, 진행 저장, 꽃잎 회수 엔딩.
상담센터 운영 정보는 제공된 요청서만 사용했습니다.
원본 캐릭터 이미지는 assets/pium-original.png에 보존했습니다.
게임용 피움이와 마을 배경은 원본 캐릭터를 참고한 생성 이미지입니다. 생성 도구와 프롬프트는 asset-notes.md에 기록했습니다.

6. 확인한 항목
프로그램 실행 검사: 실제 이동 함수로 모든 문까지 접근, 다섯 퀘스트부터 엔딩까지 전체 진행,
피움이센터 선행 방문, 퀴즈 오답 후 재선택, O/X 오답 해설, 중복 꽃잎 방지,
저장 후 이어하기, 손상된 저장 데이터·저장 차단 환경, 방향키·창 전환 입력 해제,
조이스틱 취소, 건물·분수·꽃밭 충돌 및 입장 제한.
브라우저 화면 확인: 390×844 모바일 세로 화면, 작은 화면, 이미지 로딩, 가로 넘침 없음.
실제 iOS/Android 기기 검사는 수행하지 않았습니다.
